_**Overview**_:

The Safety Inspection Workflow Tool is a Java-based desktop application built using Swing. It enables users to manage and log safety inspections efficiently by providing features to record, view, save, and load inspection data in a tabular format.

_**Features**_:

**Log Inspections**: Record inspection details, including the area inspected, issues found, and severity level.
**Save Checklist**: Save the inspection checklist to a CSV file for easy sharing and archival.
**Load Checklist**: Load a previously saved checklist from a CSV file to continue working on it.
**User-Friendly Interface**: Simple and intuitive interface with table-based visualization for inspection records.

_**Requirements**_:

Java Development Kit (JDK) 8 or higher.

_**How to Run**_:

**Compile and run the application:**

javac SafetyInspectionTool.java  
java SafetyInspectionTool  

_**Usage**_:

**Log Inspection:**
Enter the area inspected, issues found, and select the severity level.
Click on the "Log Inspection" button to add the details to the table.

**Save Checklist:**
Click on the "Save Checklist" button.
Select the desired location to save the checklist as a CSV file.

**Load Checklist:**
Click on the "Load Checklist" button.
Select a CSV file to load inspection data into the table.

_**Example**_

**Input:**

**Area**: "Warehouse A"
**Issues Found**: "Leaking pipe"
**Severity**: "High"

**Output:**

Table entry added with the above details.
